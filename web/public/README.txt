# FAB-1 Web 導覽

由最終 `out/digital_twin/FAB1_DigitalTwin.blend` 匯出，提供「一鍵導覽＋自由探索」。原生 Blender 主檔未修改。

## 展示套件：不用安裝 npm 套件

解壓縮 `FAB1-Web-Tour.zip`，保留完整目錄。電腦需已安裝 Node.js。

1. 雙擊 `Start-Tour.cmd`。
2. 開啟 http://127.0.0.1:4174 。
3. 關閉命令視窗即停止服務。

也可執行 `node serve.mjs 4175` 改用其他連接埠。不能直接雙擊 `dist/index.html`；瀏覽器需以 HTTP/HTTPS 取得模型與解碼器。

## 原始碼開發

使用 Node.js 22.12 或以上版本，在 web 目錄執行：

```powershell
npm ci
npm run dev -- --port 4173
```

正式建置：

```powershell
npm run build
node serve.mjs
```

將完整 `dist/` 部署至一般靜態網站主機即可分享。支援子目錄部署；模型、共享材質、解碼器及授權檔須一併保留。線上版：https://robertoshiu.github.io/fab1-3d-cad/ 。推送 main 分支會由 GitHub Actions 自動建置與部署。

## 操作

- 開始導覽：外觀、樓層關係、1F 製程、B1 支援設備、2F 空調夾層、屋頂，共六站約 72 秒。
- 拖曳旋轉；滾輪或雙指縮放；右鍵拖曳或方向鍵平移。
- 操作模型會暫停導覽，可續播、跳站或切換自由探索。
- 自由探索支援樓層隔離、外殼開關、樓層分離、系統篩選、設備搜尋與點選資訊。
- 手機操作面板可收合；深淺色主題可切換；減少動態偏好將停用自動播放與鏡頭補間。

## 資料與限制

這是依設計資料建立的視覺孿生，沒有即時設備狀態或感測連線。未取得實測或原廠尺寸的構件採推導尺寸，並非經核定施工圖或經驗證的竣工模型。

模型來自最終 Blender 主檔；材質轉成 Web PBR。瀏覽器即時光影與 Cycles 離線圖片不完全相同。模型的系統配色與來源 ID 保留；搜尋結果直接使用來源設備名稱。

六份 GLB 保留 2,569 個網格、1,868,611 個三角形與全部 2,586 個 CAD 來源 ID。GLB、共享 WebP 與 HDR 合計約 21.49 MB。Draco 保留拓樸並量化頂點；解碼後包圍盒最大偏差為 0.131 mm。原 Blender SHA-256 已核對未變。

## 3D 效能模式

- 自動：手機或觸控裝置使用流暢模式，桌面使用精細模式。
- 流暢：畫布像素倍率上限 1，停用即時陰影、微表面法線與各向異性，玻璃改用較省資源的透明材質。模型幾何與設備選取仍完整保留。
- 精細：畫布像素倍率上限 1.5，保留完整材質、陰影及折射。
- 自由探索的「顯示品質」可手動切換。

2,384 個靜態物件合併為 313 個繪圖批次，按樓層、系統、材質、外殼狀態及空間區塊分組。桌面同一總覽視角繪圖呼叫由 5,106 降為 964（減少 81.1%）。手機觸控模擬的流暢模式為 508 次。187 萬個原始三角形及全部設備 ID 未刪減；這是繪圖工作量的比較，不代表保證 FPS。

頁面閒置時不重繪，背景分頁停止更新視角；恢復前景即可繼續操作。性能與回歸檢查詳見 PERFORMANCE_QA.json。

## 驗證

Chrome 桌面及 390×844 行動尺寸已實測導覽、搜尋、篩選、全螢幕、鍵盤焦點、減少動態與載入失敗處理。

Lighthouse 桌面本機測試：效能 60、可及性 100、最佳實務 100、SEO 100；FCP 0.6 s、LCP 1.0 s。完整 3D 初始化與透明材質仍需要較多 GPU／CPU 資源，結果不代表手機實機效能。

原始碼的 `public/model-manifest.json` 記錄來源與群組。材質來源在 `public/sources/`，授權全文在 `public/licenses/`；展示套件對應檔案位於 `dist/`。無登入、外部資料庫或 API 金鑰需求。

## 設計方向

工業模型展廳，以三維內容為主角。Taste Skill：DESIGN_VARIANCE 5、MOTION_INTENSITY 4、VISUAL_DENSITY 3。使用 React、Three.js、原生 CSS、自託管 IBM Plex 字體與 Phosphor 圖示。
